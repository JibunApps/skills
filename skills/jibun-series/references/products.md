# 製品詳細

いずれも kintone REST API で kintone アプリと接続し、kintone アカウントを持たない人向けの画面を提供する。
基盤は Google Firebase（東京リージョン）。サイボウズオフィシャルパートナー製品。

## じぶんページ（マイページ）

- 何ができるか: 招待したユーザーがログインし、kintone のレコードを **一覧・詳細・新規・編集・コメント** できる。
  複数の kintone アプリを 1 つのマイページに束ねられ、ユーザーごとに表示するアプリを選べる。
- レコードの絞り込み: 「ユーザーごとの条件」（ログインユーザーの名前・メールアドレス・カスタムフィールドと
  kintone フィールドの一致）と「全体の条件」（ステータス・日付などデータ側の条件。関数も使える）の 2 段。
  **未設定だと全レコードが見える** ので、設計時に必ず条件を決める。
- kintone のコメント機能と連携。じぶんページ側の投稿が kintone コメントに載り、通知メールも届く。
- ポータル画面（ログイン後トップ）は HTML/CSS で独自デザイン可。
- 二段階認証、言語設定（日英）、タイムゾーン変更、通知設定あり。
- オプション: セキュリティオプション（強制ログアウト期限・一斉ログアウト・パスワード強度）、IP アドレス制限対応オプション。
- 典型ユースケース: 取引先ポータル、会員マイページ、フランチャイズ加盟店の発注画面、経費・各種申請の受付、
  アルバイト従業員のデータ管理（紙の申請書の置き換え）。
- トライアル: **無期限・利用者 2 名まで**（管理者は何名でも）。3 名目以降は有料プラン。

## じぶんフォーム（Web フォーム）

- 何ができるか: kintone アプリのフィールドから項目を選ぶだけで、kintone に直接レコードを登録する Web フォームを作る。
  フォーム数は無制限。見出し・説明文の追加、横並びレイアウト、編集不可（表示のみ）項目の設置が可能。
- 自動返信メール（本文にフォーム値を差し込み可、Cc/Bcc 対応）。スパム対策設定あり。
- 多言語対応（日本語・英語）。二段階認証（管理画面）。
- じぶんレコードと連携すると、投稿と同時にレコード URL を発行して自動返信メールに載せられる。
- 典型ユースケース: お問い合わせフォーム、申込・応募フォーム、アンケート、加盟店からの発注受付。
- トライアル: **30 日間**。

## じぶんレコード（1 レコードの外部共有）

- 何ができるか: kintone の **特定レコードごとに固有 URL** を発行し、ログイン不要で閲覧・編集・コメント・ファイル添付させる。
- URL の作成は手動、または kintone Webhook（レコード追加）をトリガーにした自動作成。
  作成した URL を kintone レコードのフィールドに自動反映する設定もある。
- パスワード付与（自動生成／管理者指定）、公開終了日時の設定、利用者によるコメント削除可否の設定。
- 典型ユースケース: 案件ごとの顧客サポート窓口、採用応募者ごとのやり取り、取引先との 1 案件 1 URL の情報共有。
- トライアル: **30 日間**。

## じぶん kintone プラグイン（社内ユーザー向け・標準機能の拡張）

- 何ができるか: 採番・ルックアップ強化・テーブル操作・転記・一括更新・集計・通知・表示カスタムなど 42 種のプラグインを、
  **定額・ユーザー数無制限・アプリ数無制限** で提供。JavaScript カスタマイズを書かずに標準機能の壁を越える。
- プラン: チョイス（5 種を選択）／コンプリート（全種）。トライアル 1 ヶ月。プラグインファイルが納品され、自分でセットアップする。
- 対象外: Zoom Phone 連携・Zoom Revenue Accelerator 連携（プレミアム・別サービス）、カスタマイズ開発。
- 詳細と「困りごと→プラグイン」対応表は [plugins.md](plugins.md)。

## 併売されている関連製品（このスキルの主対象外）

- Zoom Phone × kintone 連携プラグイン: ワンクリック発信・通話記録の kintone 集約。
- じぶん kintone コーチ: kintone 活用のオンライン伴走サポート。
