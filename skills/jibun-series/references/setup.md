# セットアップ手順（人が管理画面で行う作業）

じぶんシリーズには管理画面を操作する公開 API が無い。以下は **利用者に案内する手順** であり、
AI エージェントは kintone 側の準備（アプリ・フィールド・専用ユーザー・権限）までを担う。

## 1. トライアル環境の作成

1. 各製品ページの「無料トライアル」からメールアドレスとパスワードを登録すると、お試し環境が即時発行される。
2. 届いたメールの URL からパスワードを設定し、ログインする。
3. トライアル期間: ページは無期限（利用者 2 名まで）、フォーム／レコードは 30 日。
   有料プランへの申込は **トライアル環境内の申込フォーム** から行う（先に環境を作るのが前提）。

## 2. kintone 側の準備（エージェントが設計・生成する範囲）

1. **じぶんシリーズ専用の kintone ユーザーを作成する**。監査ログ上、じぶん経由の全操作がこのユーザーの操作になるため、
   個人アカウントは使わない。
2. 専用ユーザーに、連携アプリのレコード閲覧・追加・編集の権限を付与する。コメント機能を使う場合はコメント権限も。
3. 連携する kintone アプリを [field-support.md](field-support.md) の対応表に沿って設計する。
   ページで「本人のレコードだけ見せる」なら、突合キー（メールアドレス等）のフィールドを必ず持たせる。
4. kintone に IP アドレス制限をかけている場合は、じぶん側で「IP アドレス制限対応オプション」の申請が必要
   （トライアル中無料・契約後は月額オプション）。固定化された IP を kintone の許可 IP に追加する。

## 3. じぶん側の接続とアプリ作成

1. 管理画面の「kintone との接続設定」で、kintone のドメイン名と専用ユーザーのアカウント情報を入力して接続する。
2. 「アプリを作成する」で連携する kintone アプリを選び、利用者に見せるタイトルを設定する。
3. 画面ごとに表示・編集する項目を選ぶ。
   - ページ: 一覧 / 詳細 / 新規追加 / 編集 の各画面と、「ユーザーに見せられるレコード条件」を設定する。
   - フォーム: フォーム画面のパーツ配置、自動返信メール、スパム対策を設定する。
   - レコード: 詳細 / 編集 画面と、URL の作成方法（手動 or Webhook 自動）、パスワード・公開終了日時を設定する。
4. **kintone アプリのフィールドを追加・変更したら、じぶん側アプリの「同期」ボタンを押す**。
   これを忘れると、新しいフィールドが選べない・保存に失敗する。トラブル相談の最頻出原因。
5. ページの場合は「ユーザーを招待する」で名前とメールアドレスを登録し、招待メールからログインさせる。

## 4. じぶんフォーム → じぶんレコード 連携（受付後のやり取りを続けるパターン）

1. じぶんレコード側で「自動化の共通設定」を開き、自動通知メールの通知先メールアドレスフィールド（kintone アプリ側）、
   返信先アドレス、送信元名を設定する。
2. kintone アプリの Webhook 設定に、じぶんレコードの Webhook URL を登録し、「レコードの追加」（コメント機能を使うなら
   「コメントの書き込み」も）にチェックする。設定後、kintone の「アプリを更新」を忘れない。
3. じぶんフォームからの投稿で kintone にレコードが追加されると、じぶんレコードが URL を自動発行し、
   自動返信メールに載せて回答者へ送る。以降のやり取りはそのレコード URL 上で行う。

## 公式マニュアル

- ページ: https://www.jibun-apps.jp/jibun-page/support/ （はじめかた / アプリを作成する / ユーザーを招待する / レコード条件の設定 / 同期ボタン）
- フォーム: https://www.jibun-apps.jp/jibun-form/support/ （はじめかた / フォーム画面を設定する / 自動返信メール / じぶんレコードと連携する）
- レコード: https://www.jibun-apps.jp/jibun-record/support/ （URL を自動作成する / パスワードを付与する / URL 情報を kintone に自動反映）
